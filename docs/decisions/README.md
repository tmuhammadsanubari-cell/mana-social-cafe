# Catatan keputusan (ADR)

Arsitektur dasar sudah tercatat di PRD 13.1 dan 13.2 (situs statis Astro + Sanity). Folder ini untuk keputusan berikutnya: versi yang dikunci, pilihan hosting, penyimpangan dari PRD, atau jawaban pemilik yang mengubah implementasi.

Nama file: `NNNN-judul-pendek.md`, misalnya `0001-versi-stack-m01.md`.

## Templat

```markdown
# NNNN: Judul keputusan

- Tanggal: YYYY-MM-DD
- Status: diusulkan | diterima | diganti oleh NNNN
- Rujukan PRD: (misalnya 13.2, R-07, Q-05)

## Konteks
Masalah atau pertanyaan yang memicu keputusan ini.

## Keputusan
Yang dipilih, dalam satu atau dua kalimat.

## Alasan dan konsekuensi
Kenapa opsi ini, opsi lain yang ditolak, dan dampaknya ke kode atau PRD.
```
